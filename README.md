# Single Page Application (SPA) UI & Responsive Design

This project builds a complete responsive UI for a website. It demonstrates how to create a Single Page Application where pages change without reloading, providing a smooth and modern user experience.

## 🚀 Features

- **Single Page Application (SPA)** - Seamless navigation without page reloads
- **Responsive Design** - Optimized for all device sizes
- **Smooth Scrolling** - Navigate to specific sections with smooth animations
- **Modern UI Components** - Clean and intuitive user interface

## 🛠️ Technologies Used

- **React Router DOM** - Client-side routing for SPA functionality
- **React Icons** - Beautiful and consistent iconography
- **SASS/SCSS** - Advanced CSS preprocessing for better styling
- **React Router Hash Link** - Smooth scrolling to specific sections (like "About" or "Brands") without causing full page reloads

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd one
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

## 🎯 Usage

The application provides smooth navigation between different sections and pages. Use the navigation menu to explore different areas of the website, with smooth scrolling animations enhancing the user experience.

## 📱 Responsive Design

The application is fully responsive and works seamlessly across:
- Desktop computers
- Tablets
- Mobile devices
